Черновики постов атласа с картинкой (карточка сравнения с сайта). Робот эту папку НЕ читает.

Картинка и цифры сняты с локальной сборки сайта скриптом latam-atlas/scripts/compare-card.mjs.
Проверить черновик: `python3 publish.py --queue atlas --dry --dir queue-atlas-draft --id <папка>`.
После «да» Артема папку переименовать и перенести в queue-atlas/ (имя задаёт место в очереди),
закоммитить и запушить вместе с card.png: Threads забирает картинку по raw-ссылке GitHub.
